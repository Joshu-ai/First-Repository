# Sage Finance Short: $100 invested in 1928, ranked

A 32-second Sage Finance (formerly Daikoku) Short ranking what $100 invested at the start of 1928 was worth at the end of 2025: S&P 500, corporate bonds, gold, Treasury bonds, home prices, Treasury bills and cash in a drawer. It closes on the 1929–1932 crash and a held-on-or-sold question.

| File | What it is |
|---|---|
| `SageFinance_Rank1928.mp4` | Upload copy (1080×1920, 30 fps, HEVC, under 10 MB) |
| `UPLOAD_SHEET.md` | Title, description, pinned comment, proposed slot, script and per-figure source check |
| `qa_sheet.jpg` | 12-frame QA contact sheet |
| `rank_1928.js` | Scene code (Studio Kit design system) |
| `scripts.py` | Kit script file; the `rank_1928` entry holds the VO lines |
| `research.json` | Every citation found for each figure, with researcher and verifier notes |

To rebuild: set up the Sage Finance Studio Kit (formerly Daikoku Studio Kit), put `rank_1928.js` in `web/`, use this `scripts.py`, and add a `rank_1928` CHORDS entry to `audio.py`. Then run `python3 voice.py rank_1928` and `bash build_one.sh rank_1928 SageFinance_Rank1928`.
